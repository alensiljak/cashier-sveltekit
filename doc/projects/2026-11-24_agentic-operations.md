# Agentic Operations

Integrate an agent so that it can run Cashier on user's behalf.
Expose functionality. Research what standards are there for this.

Examples:

- create new transaction
- show scheduled transactions
- open calendar
- open reports

## Features

### Creating New Transaction

Integrate AI in addition to NLP for quick creation of transactions. The user speaks to the app and a transaction is created with the best match. Similar to the current NLP but using an LLM, instead, for interpretation.
