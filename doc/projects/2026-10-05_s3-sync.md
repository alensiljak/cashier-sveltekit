# S3 Sync

## Goal

Always-on live backup and sync unit. Minimal setup and infrastructure.

## Design

- Use an S3 bucket as an online storage mechanism. Accessible from the browser directly, no middlemen.
- Synchronize the OPFS storage directly. Skip the local storage step.
- Encrypt the data at rest and decrypt transparently on the fly.
- Encrypt each file individually.
- Each device keeps own manifest. This is the pattern for p2p file sync.

- [ ] CORS on S3 bucket
- [ ] credentials storage
